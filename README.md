# Samsung-Custom-Screenshot-App-Suffix
A One UI 8 module that prevents empty screenshot filename suffixes caused by non-ASCII character stripping, enabling customizable fallback names for affected apps.




## Detailed Introduction

#### This test was conducted only with OneUI 8; its availability on other versions of OneUI cannot be guaranteed.
#### Single-photo, single-write database operation prevents corrupted duplicates.
#### After capturing a screenshot, the Samsung Smart Capture toolbar will pop up at the bottom as expected.
#### Only HOOK selected apps.

## Plan
#### Achieve system-wide takeover, allowing custom screenshot names for any app.
#### Toggle between dark and light mode
#### Supports multi-language suffix formats (currently only English is supported).
